# Nistula Technical Assessment

This repository contains the backend implementation for the Nistula Guest Message Handler, the PostgreSQL database schema for a unified messaging platform, and strategic responses to guest experience scenarios.

## Project Structure
- `app/`: Modular backend source code (FastAPI)
    - `main.py`: Application entry point
    - `routes/`: API endpoint definitions
    - `services/`: Business logic (Claude API, classification, confidence, normalization)
    - `models/`: Pydantic data models for request/response validation
    - `config.py`: Environment configuration
- `schema.sql`: PostgreSQL database design for unified messaging
- `thinking.md`: Answers to strategic guest experience and system design questions
- `tests/`: Verification payloads and test data
- `requirements.txt`: Python dependencies

## Part 1: Guest Message Handler

### Setup Instructions
Follow these steps to set up the project locally after cloning:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/ravi7317/nistula-technical-assessment.git
    cd nistula-technical-assessment
    ```

2.  **Install dependencies**:
    Ensure you have Python 3.9+ installed, then run:
    ```bash
    pip install -r requirements.txt
    ```

3.  **Configure Environment Variables**:
    The `.env` file is ignored by Git for security. You **must** create a new `.env` file in the root directory based on the provided template:
    *   Copy `.env.example` to `.env`
    *   Add your **Anthropic API Key** to the `ANTHROPIC_API_KEY` field.
    ```env
    ANTHROPIC_API_KEY=your_actual_key_here
    PORT=8000
    DEBUG=True
    ```

4.  **Run the Server**:
    Start the FastAPI backend using:
    ```bash
    python -m app.main
    ```

### Webhook Endpoint
- **URL**: `POST /webhook/message`
- **Method**: `POST`
- **Sample Payload**:

  ```json
  {
     "source": "whatsapp",
     "guest_name": "Rahul Sharma",
     "message": "Is the villa available from April 20 to 24? What is the rate for 2 adults?",
     "timestamp": "2026-05-05T10:30:00Z",
     "booking_ref": "NIS-2024-0891",
     "property_id": "villa-b1"
  }
  ```

### Confidence Scoring Logic
The confidence score (0.0 to 0.98) is generated by the AI (Claude 3.5 Sonnet) based on a realistic probabilistic assessment:
1.  **Context Match**: How well the property context provides a direct answer.
2.  **Ambiguity**: Clarity and specificity of the guest's request.
3.  **Realistic Scoring**: The system avoids artificial perfection (never returning exactly 1.0) to represent a true production-grade AI model.

**Action Mapping**:
- `auto_send`: Score > 0.85
- `agent_review`: Score 0.60 - 0.85
- `escalate`: Score < 0.60 or query classified as a **complaint**.

## Part 2: Database Schema
The schema in `schema.sql` is designed for a unified messaging platform. Key features:
- **Unified Messaging**: Single table for all channels with sender type tracking.
- **AI Metadata**: Inbound messages store classification and confidence scores.
- **Contextual Linking**: Conversations link guests to reservations for full context.
